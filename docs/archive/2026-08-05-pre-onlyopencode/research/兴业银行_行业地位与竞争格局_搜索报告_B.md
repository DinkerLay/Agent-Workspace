## 三、"商行+投行"战略

### 3.1 战略内涵

兴业银行以"商行+投行"为核心战略方向，在商业银行业务基础上大力发展投资银行业务，通过债券承销、资产证券化、REITs、结构化融资、财务顾问等投行类业务构建差异化优势。

### 3.2 战略执行表现

| 业务领域 | 关键成果 | 来源 |
|----------|----------|------|
| **非金融企业债务融资工具承销** | 2020年承销规模6541.8亿元，服务575家企业，均排名**市场第一** | 2021年大事记 |
| **熊猫债** | 2024年作为唯一股份制银行联席主承销，助力新开发银行(NDB)发行60亿元熊猫债 | 2024年大事记(2月) |
| **类REITs** | 首单银行间高速公路类REITs、首单商务写字楼类REITs、首单绿色+科创双标类REITs | 2024年大事记 |
| **科创债券** | 首单数字人民币科创债券、首单"蓝色+科创"创新债券 | 2024年大事记 |
| **离岸债券** | 2022年以DMI和SereS数据排名中资离岸债券承销**双料第一** | 2023年大事记(1月) |
| **资产担保债券** | 首单结构化资产担保债券、首单央企知识产权资产担保债券 | 2024年大事记(9月) |

### 3.3 战略评价

**优势**: 债券承销领域具备显著领先优势，尤其在创新品种(绿色债券、科创债券、数字人民币债券)方面建立先发优势。类REITs和资产证券化领域创新能力突出。

**风险**: 投行业务对资本市场活跃度敏感度高；"商行+投行"战略在资本占用、风险隔离方面面临监管约束。

## 五、竞争优势与劣势

### 5.1 核心竞争优势

1. **绿色金融先发优势**: 十余年深耕绿色金融，ESG评级全球领先，构成品牌护城河
2. **投行业务创新能力**: 债券承销、REITs、结构融资创新领先市场
3. **同业生态壁垒**: 银银平台构建强大的B端网络效应
4. **财富管理品牌**: 兴银理财行业排名前列，综合理财能力连续多年第一
5. **科技投入**: 在AI、卫星遥感、数字人民币等领域形成差异化科技能力
6. **ESG/可持续发展**: AAA评级产生的品牌溢价和国际认可

### 5.2 竞争劣势/风险

1. **规模劣势**: 相比国有大行(30-50万亿级别)，资产规模(~10万亿)差距显著
2. **净息差收缩**: 行业性利率下行环境下，以利息收入为主的盈利模式承压
3. **房地产风险敞口**: 行业性房地产债务风险影响资产质量
4. **属地局限**: 总部位于福州(非北上深)，在人才吸引和政策信息获取方面不如一线城市总部银行
5. **资本市场表现**: 股价1年下跌21%, P/E仅5.71x, 反映市场对行业和公司的担忧
6. **增长放缓**: 2024年营收同比下降(从2223.74亿降至~2080亿)，净利润基本持平，增长动力不足

## 六、行业环境与监管政策影响

### 6.1 宏观环境

| 因素 | 影响方向 | 描述 |
|------|----------|------|
| 利率下行 | 利空净息差 | LPR持续下调，银行利息收入承压 |
| 经济增速放缓 | 利空资产质量 | 企业盈利能力下降，不良贷款压力上升 |
| 房地产调整 | 利空信用风险 | 房企流动性风险传导至银行资产端 |
| 人民币国际化 | 利好跨境业务 | 人民币跨境收付增长(CIF: 2023年跨境收付突破2万亿) |

### 6.2 监管政策

| 政策方向 | 影响 |
|----------|------|
| **中央金融工作会议** (2023.10) | 明确做好 **科技金融、绿色金融、普惠金融、养老金融、数字金融** "五篇大文章" → 利好兴业绿色金融/科技金融布局 |
| **金融监管总局成立** | 监管趋严，但股份制银行定位更为明确 |
| **支持房地产融资** | "城市房地产融资协调机制" → 缓解部分风险但增加敞口 |
| **地方债务化解** | 影响政府类平台贷款 |
| **资本市场改革** | 债券市场开放(互换通等) → 利好投行业务 |
| **数字人民币推广** | 兴业作为指定运营机构 → 先发优势 |

### 6.3 行业竞争态势

- 国有大行在低利率环境下凭借低成本负债优势进一步挤压股份制银行空间
- 股份制银行内部呈现分化: 招行聚焦零售, 兴业聚焦绿色+投行, 中信聚焦对公
- 金融科技(互联网平台、数字货币)带来跨界竞争压力

## 七、关键发现总结

### 7.1 核心结论

1. **差异化定位鲜明**: 兴业银行是股份制银行中"绿色金融+投资银行"战略最坚定的执行者，在MSCI ESG评级(AAA)和债券承销领域具备行业领先地位
2. **规模跃升**: 2023年总资产突破10万亿元(10.16万亿)，一级资本全球排第16位，是股份制银行中少数突破10万亿大关的机构
3. **创新力突出**: 在绿色债、熊猫债、REITs、数字人民币债券等领域创造多项"首单"纪录，产品创新能力行业领先
4. **盈利能力承压**: 2024年营收净利润增速放缓，股价表现不佳(P/E 5.71x)，市场对增长前景存在担忧
5. **分化竞争格局**: 在国有大行压迫和互联网金融冲击下，兴业依靠绿色金融护城河和同业生态维持差异化壁垒
