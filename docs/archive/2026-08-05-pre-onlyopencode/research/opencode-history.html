核心设计理念

根据项目内部规范文档 AGENTS.md 架构:search-c

  • 状态化多智能体工作台 (stateful multi-agent workbench)
  • 调度器职责与智能体推理职责分离 — 保持组件边界清晰
  • 审查与验证文化 — "完成"需要审查、验证和记录上下文
  • 三层循环架构:
    1. 研究/规范循环 — 维护产品事实 (docs/research/, docs/superworks/spec/)
    2. 规划循环 — 将规范转为可执行计划 (docs/superworks/plans/)
    3. 执行循环 — 将计划转为代码、验证、记录上下文
  • AGENTS.md 指令体系 — 分层嵌套、Scope And Priority 机制

商业模式

OpenCode 采用开源核心 + 商业化服务模式:search-c

OpenCode Zen — 精选模型服务

由 OpenCode 团队测试和基准测试的精选模型列表。用户通过 /connect 命令开通，或前往 opencode.ai/auth 获取 API key。

OpenCode Go — 低价订阅方案

2026年7月推出。首月 $5，之后 $10/月。包含 Grok 4.5、GLM-5.2、Kimi K3、DeepSeek V4 Pro/Flash、Qwen3.7 Max/Plus、MiMo-V2.5 等开源模型的可靠访问。采用额度系统 (每5小时刷新)，可购买额外充值包。支持与任何 agent 配合使用。

Enterprise — 企业版

隐私敏感环境的部署方案。不存储用户代码或上下文数据。支持自托管和私有部署。

3. 边界定义（Boundedness）
